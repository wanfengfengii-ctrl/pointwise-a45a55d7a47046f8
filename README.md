# 青岚流域遥测日表湖

青岚流域资料中心按站日接收水文读数。白班巡检员凭入账回执核对原报送及缺测，档案员根据更正单冻结正式版本。夜班在断开源库后按冻结号复核已到冷页，先交付可以引用的读数和出处，再按待恢复范围补收原页。

## 一天的交接

1. 四号站交来日报。每行包含整数键、整数升数或 `None`，以及非负原行位置。巡检员提交站日和批次号，正式底版与入账回执一起保存。
2. 站端原样重投时复领原回执。原站日、行顺序、键、读值或原位置变化时，同批次号报冲突。重复初始化保留报送、修订和已经发行的历史。
3. 档案员以指定父版为依据，用 `B=13` 替换 `[A,C)`，因此原来的 `A=5` 被撤下，紧接右端的 `C=11` 保留。后一张更正用空行集清除 `[B,C)`。
4. 档案员冻结所选修订并交付原号目录。目录列出底版、每次正式更正声明及精确冷页。旧号仍可领取首次发行的目录和页体。
5. 夜班登记目录，先实收底版与后一张空页。登记目录只建立预期页清单，精确页校验并提交后才可用于核账。
6. 中间页未到时，`[B,C)` 已核实为空，可签零行、零缺测、零升。`[A,D)` 可交付 `C=11` 及原报送位置，`[A,B)` 待恢复，因此整窗汇总省略。
7. 另一冻结号下读数相同的页被拒收。补收确切页后按原号复核，整窗已核实为一行、零缺测、十一升。隔离仓重开及同页重投保留正式实收和回执。

## 运行

使用 Python 3.11 和标准库。控制台物化后可运行完整回归。

```sh
python3 -B check_project.py
```

可直接通过 `python3 -B -m unittest discover` 发现 `tests/` 中的全部测试。以下命令使用 `examples/day.json` 实际运行报送、发布、冻结、实收及离线补核。源账和隔离仓都位于一次性的临时目录。演示核对手算预期后输出交班记录。

```sh
python3 -B demo.py
```

## 公开接口

从 `lake` 导入以下接口。源账使用调用方持有的 `sqlite3.Connection`，先调用 `initialize_source(db)`。`open_inventory(path)` 返回隔离仓连接。调用方负责关闭连接。事务入口应在连接没有挂起事务时调用，并发会话各自使用独立连接。

| 调用 | 返回及用途 |
| --- | --- |
| `submit(db, batch_id, station, day, rows)` | `SubmissionReceipt` 含批次号、底版修订号、总行数及缺测数。`day` 使用有效的 `YYYY-MM-DD` 日期，`rows` 为按原报送顺序传入的 `(key, liters, position)`。 |
| `amend(db, correction_id, parent_id, lo, hi, rows)` | 新修订号。`rows` 使用同样的三元组，原位置对应更正单。已登记的更正号拒绝再次使用。 |
| `get_revision(db, revision_id)` | 指定正式日表的 `ReadingRow` 元组，按键序排列。 |
| `freeze_table(db, request_id, revision_id)` | `IssueReceipt` 含请求号、正式修订号及冻结号。相同请求号和修订号可重复领取。 |
| `fetch_bundle(db, freeze_id)` 和 `read_page(db, identity)` | 原 `FrozenManifest` 及按清单精确身份取得的页体字节。清单可用 `lake.issue.manifest.encode_manifest` 转为可传输字节。 |
| `accept_page(cold, manifest)` 或 `accept_page(cold, freeze_id, identity, payload)` | 前者返回已登记清单，可传清单对象或编码字节。后者返回 `IntakeReceipt`，再次核验后可复领原回执。 |
| `audit_window(cold, freeze_id, lo, hi)` | `WindowResult` 含键序行、`verified_ranges`、`pending_ranges` 和完整时的 `totals`。部分窗口的 `totals` 为 `None`。 |

## 计量与失败语义

区间要求整数端点且 `lo < hi`，左端包含，右端排除。键、升数和原位置保留精确整数。读取值 `None` 表示行存在但缺测，零升为有效读值。输入中的布尔值、浮点数和字符串不作为整数。更正撤下声明区间内的全部父版行，再写入完整替换行集。保留区间外行及其出处。

底版覆盖取最小键至最大键后一个整数，空底版没有覆盖。底版覆盖以外且无更正声明的区间已知无行。每段取最后一个覆盖其键的正式声明。该页未实收时该段待恢复，哪怕该页最终是空页。已实收的空替换页可核实其最后负责的整段。相邻同状态范围在输出中合并。核账行保留原负责页、该页的一起始位置和上游原记录位置。只在整窗没有待恢复范围时给行数、缺测数和非空升数合计。

源库与隔离库使用 SQLite。整数在持久记录和线格式中用十六进制文本无损编码，公开 API 返回 Python 整数。隔离端从档案员交接的可信目录获取预期页身份，并核对页体字节的 SHA-256、页头、行序和来源。页或清单校验失败、请求冲突、非法值及非法区间报 `ValueError`，合法标识指向未知修订、冻结件或归档页时报 `KeyError`。持久写入及提交失败抛出 SQLite 错误。每次核账使用同一读事务的清单及实收页快照。

`lake/ingest` 保存站批原件和拒收，`lake/revision` 保存正式声明链，`lake/issue` 保存冻结交接件，`lake/receive` 保存隔离库存，`lake/reconcile` 产生核账结果。四份业务回归覆盖重投、正式历史、区间更正、缺页对照、原页出处、精确计量及失败后重开重试。
